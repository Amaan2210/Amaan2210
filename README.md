## 🧰 Open Source

- **[AFK](https://github.com/AmaanKhan63/afk)**: a Node daemon that wraps every Claude Code, Codex or shell session in a pseudo-terminal, plus an Android app over Tailscale that streams the terminal and answers the agent's questions. Closing the app does not stop the session.
- **[Toolkit](https://github.com/AmaanKhan63/toolkit)**: an Android toolbox in Kotlin and Jetpack Compose. PDF tools, Office conversions, camera scanning, viewers. Everything on device, no backend, no account, no analytics.
